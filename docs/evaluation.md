## How the set is labelled

- Demo scenarios: labelled in `satyapan/satyapan/evaluate.py` (GENUINE_SCENARIOS; every other scenario is an in-scope scam).
- Variant corpus: by each variant's own `from` and `expected` fields (`evaluate.variant_label`). Script fragments with no sender, and scam openers with no demand yet, count as scams outside scope.
- `satyapan/data/eval/labelled.json`: labelled by hand, one line each, with the category shown above.
